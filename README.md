# 🌲 Tesla(TSLA) 1개월 주식 대시보드 & 리포트

초보자도 한눈에 이해하기 쉽게 구성된 테슬라(TSLA) 최근 1개월 주식 요약 웹 대시보드 및 리포트입니다.

> ⚠️ **안내사항 (투자 유의사항)**  
> 본 대시보드는 **저장된 정적 자료(수집 시점 기준)**를 바탕으로 작성된 **AI 초안**입니다. **실시간 시세가 아니며**, 투자 권유를 위한 목적이 아닙니다. 실제 매매 시에는 최신 공시 및 실시간 시세를 필히 확인하시기 바랍니다.

---

## 📌 주요 특징
- **포레스트 감성 UI**: 세쿼이아 숲 배경과 글래스모피즘(Glassmorphism) 카드 디자인 적용
- **초보자 눈높이 맞춤 해설**: 핵심 3줄 요약, 용어 사전, 체크리스트 제공
- **엄격한 데이터 구분**: `[사실]`, `[AI 해석]`, `[미확인 / 확인 필요]` 배지 표기
- **검증된 데이터 & 출처 링크**: Yahoo Finance 시세 API 데이터 및 5건의 최신 뉴스 원문 링크 연결
- **A4 인쇄 & PDF 내보내기 최적화**: 인쇄 시 자동 화이트 테마 전환 및 페이지 잘림 방지 스타일 적용
- **단독 실행형 HTML 지원**: 외부 의존성 없이 로컬 오프라인에서도 열리는 `stock-report.html` 제공

---

## 📊 데이터 기준 요약
- **종목명**: Tesla, Inc. (테슬라)
- **종목코드 / 거래소**: `TSLA` / NASDAQ
- **통화 단위**: USD ($)
- **자료 기준 기간**: 2026-10-14 ~ 2026-11-13 (총 23거래일)
- **1개월 시작가 / 마감가**: $367.16 ➔ $390.22 (▲ +$23.06 / +6.28%)
- **데이터 출처**: Yahoo Finance 공개 API 수집본 (`tsla_data.json`)

---

## 📁 파일 구성
- `index.html`: GitHub Pages 웹 서비스용 메인 대시보드
- `stock-report.html`: 이미지와 차트 라이브러리가 내장된 단독 실행/배포용 리포트
- `stock-report.pdf`: A4 인쇄 최적화 PDF 리포트
- `forest_bg.jpg`: 대시보드 배경 이미지
- `tsla_data.json`: 23거래일 정제 시세 데이터
- `tsla_news.json`: 관련 최신 뉴스 수집 및 검증 데이터

---

## 🛠️ 로컬 실행 방법
저장소를 클론하거나 다운로드한 후 웹 브라우저에서 `index.html` 파일을 더블클릭하여 바로 열 수 있습니다.

```bash
# 로컬 웹 서버 실행 (선택 사항)
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
